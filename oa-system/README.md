# 智能OA系统 - 组织协作平台

一个现代化的组织机构和成员交互性强的OA系统，提供完整的组织管理、成员协作和工作流程管理功能。

## 🌟 系统特性

### 1. 组织架构管理
- **可视化组织架构图** - 直观展示部门层级关系
- **部门管理** - 创建、编辑、删除部门，设置部门负责人
- **成员分配** - 灵活分配成员到不同部门
- **权限控制** - 基于角色的权限管理系统

### 2. 成员管理
- **成员档案** - 完整的成员信息管理
- **状态管理** - 在职/离职状态切换
- **详细信息** - 成员工作统计和活动记录
- **批量操作** - 支持批量导入和管理

### 3. 工作台功能
- **实时统计** - 组织关键指标实时展示
- **快捷操作** - 常用功能快速访问
- **最近活动** - 组织动态实时更新
- **通知中心** - 重要消息及时推送

### 4. 协作办公
- **工作流程** - 可配置的审批流程
- **任务管理** - 任务分配、跟踪和完成
- **即时通讯** - 团队成员实时沟通
- **文档中心** - 文档共享和版本管理

### 5. 信息管理
- **公告通知** - 重要信息发布和推送
- **日程安排** - 会议和活动管理
- **数据报表** - 组织效能分析报告

## 🚀 快速开始

### 环境要求
- 现代浏览器（Chrome、Firefox、Safari、Edge）
- 支持ES6+的JavaScript环境

### 安装和运行

1. **下载项目**
```bash
git clone [项目地址]
cd oa-system
```

2. **启动服务**
```bash
# 使用Python内置服务器
python -m http.server 8000

# 或使用Node.js
npx http-server -p 8000

# 或使用PHP
php -S localhost:8000
```

3. **访问系统**
打开浏览器访问：`http://localhost:8000`

## 🎯 核心功能详解

### 工作台 (Dashboard)
- **统计卡片**：显示总成员数、待处理任务、待审批流程、工作效率等关键指标
- **快捷操作**：发起流程、创建任务、发布公告、发起会议等常用功能
- **最近活动**：实时显示组织内的最新动态和活动

### 组织架构 (Organization)
- **部门卡片**：每个部门以卡片形式展示，包含部门信息、成员统计
- **部门操作**：支持添加、编辑、删除部门
- **成员展示**：显示部门下的成员列表和状态
- **详情查看**：点击部门卡片查看详细信息

### 成员管理 (Members)
- **成员卡片**：网格布局展示所有成员信息
- **成员操作**：添加、编辑、查看详情、状态切换
- **详细信息**：包含基本信息、工作统计、最近活动
- **状态管理**：在职/离职状态切换

## 🔌 API接口

### 部门管理
- `GET /api/departments` - 获取部门列表
- `POST /api/departments` - 创建部门
- `PUT /api/departments/:id` - 更新部门
- `DELETE /api/departments/:id` - 删除部门

### 成员管理
- `GET /api/members` - 获取成员列表
- `POST /api/members` - 创建成员
- `PUT /api/members/:id` - 更新成员
- `PUT /api/members/:id/status` - 更新成员状态
